# MODO GYM — Landing (Next.js 15 + three.js)

Sitio promocional de la app **MODO GYM** con hero 3D (three.js vía `@react-three/fiber`), iconos
**Iconsax** y **Phosphor**, y Tailwind CSS v4.

## Desarrollo

```bash
npm install --legacy-peer-deps
npm run dev
```

## Producción

```bash
npm run build
```

Desplegado en Vercel (Root Directory: `landing`).

## Enlaces

- App (PWA instalable): https://modo-gym.vercel.app
- Play Store: https://play.google.com/store/apps/details?id=com.modogym.app

## Tecnologías

Next.js 15 · React 19 · three.js (`@react-three/fiber` + `drei`) · Tailwind CSS v4 · framer-motion · Iconsax · Phosphor.
